# Pong — Neon Rally

A self-contained, browser-playable Pong game. No dependencies or build tools are required.

## Run it

Open `index.html` in a modern browser.

## Controls

- **W / S** or **Up / Down arrows** — move your paddle
- **Space** or **Escape** — pause or resume
- **Touch controls** — use the on-screen arrows on smaller screens
- **Restart** — reset the match

First to 7 points wins.
